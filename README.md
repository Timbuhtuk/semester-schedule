# Личное расписание · 2026–2027

Статический сайт на HTML, CSS и JavaScript. Откройте `index.html` локально или через GitHub Pages. Сборка и сервер не нужны.

## Возможности

- Просмотр по неделям и месяцам, переход между периодами и к текущей дате. Недельный вид использует равномерную часовую шкалу: положение и высота карточки соответствуют времени занятия, а пересекающиеся занятия одного дня делят ширину колонки.
- Независимые переключатели UVT и ХНУРЕ. Физкультура входит в UVT.
- Отдельный режим других групп для долгов по математике, архитектуре и испанскому. Эти занятия не добавлены в основное расписание.
- Вкладка учёта с ручными счётчиками посещений UVT и 44 чекбоксами лабораторных, практических и тестов ХНУРЕ. Отметки сохраняются в `localStorage` браузера.
- 17 недель семестра, пары UVT группы 4, выбранные пересдачи математики и архитектуры, немецкий, физкультура и 27 занятий второго университета по датам.
- Подсветка пересечений и список пар, время которых нужно проверить. В запасном режиме показаны пересечения с основными занятиями.
- Подробности занятия по нажатию на карточку; ссылку на выбранный период можно скопировать из адресной строки.

Данные находятся в `data.js` и перенесены из личной таблицы расписания. Испанский исключён. Дата занятия ЯПЗТ 19 октября в 07:45 требует подтверждения: исходная запись была `19:10-7:45`.

У второго университета известно только время начала. Для поиска **возможных** пересечений сайт использует 90-минутное окно от него; это не утверждение о реальной длительности занятия.

Оформление основано на [Tessera Storybook](https://timbuhtuk.github.io/tessera-storybook/?path=/docs/02-components-actions-controls--docs&globals=backgrounds.value:dark): палитра, типографика, прямоугольные контролы и состояния фокуса. Лицензии шрифтов — в `licenses/`.
